1. Assignment

  1. Dump Lab 08's CORDERS (each order with its line items embedded) to corders.json.
  2. Iterate through every order in that file and add it to a new RocksDB database CORDERS. Catch every flush and compaction, and for each one print the SSTables before and after it: file name, level, size, smallest key, largest key.

3. How it works

  • Dump (CordersJson.dump): iterate Lab 08's CORDERS with a read-only RocksIterator and stream each value to corders.json.
  • Load (CompactionStudy.run): read corders.json line by line, take the key from the O_ORDERKEY field, and put the order document into a fresh CORDERS in batches of 2,000. At the end, one manual flush; then poll rocksdb.num-running-compactions, compaction-pending and the flush counters until RocksDB has been idle for 1 s (RocksJava has no WaitForCompact).
  • Catching events (SstEventListener): an AbstractEventListener that turns on only the four callbacks onFlushBegin, onFlushCompleted, onCompactionBegin and onCompactionCompleted. Each callback calls db.getLiveFilesMetaData() and prints every live SSTable (name, level, size, smallest key, largest key). Begin gives the "before" list and Completed gives the "after" list. Compaction inputs are marked * and new files +. CompactionJobInfo also gives the reason, the input and output levels, and the bytes read and written. A job whose output files are the same as its inputs is a trivial move: the files are moved to a new level in the MANIFEST without being rewritten.
  • Index dump (SstIndex): RocksJava cannot read an index block, so the program decodes the block-based table format itself. It reads the 53-byte footer (magic 0x88e241b785f4cff7) and the index handle, then decodes each index entry (shared and non-shared key length, the key bytes, and a BlockHandle varint pair or a size delta). It checks the result against the TableProperties from SstFileReader: exactly one entry per data block, blocks contiguous from offset 0, and separator keys in ascending order. Every file passed.
  • Run with bash lab9/run_all.sh. It uses mvn exec:exec to run a separate JVM, because under exec:java RocksDB's native callback threads cannot find the RocksJava classes (NoClassDefFoundError: org/rocksdb/FlushJobInfo).

5. Observations

  • Flushes are the same for both styles. Each style made 20 flushes (19 because the write buffer was full, plus 1 final manual flush). Each full memtable became one L0 SSTable of about 39.6 MB holding 78,000 orders (about 134 MB of JSON, LZ4-compressed to about 30%).
  • Leveled: every compaction was a trivial move (7 compactions, 0 bytes rewritten, write amplification 1.00). corders.json is in key order, so each new L0 file covers keys above everything already stored. It overlaps nothing in the target level, so RocksDB moves the file to a new level without rewriting it (same file name before and after). With dynamic level bytes, L0 first moves straight to L6. Once L6 is larger than 256 MiB the base level becomes L5, and when L5 goes over its target a kLevelMaxLevelSize compaction moves L5 files down to L6. The final 20 files are still exactly the 20 flush outputs.
  • Universal: real merges, even for sorted input (3 merges, 1,223,950,521 bytes rewritten, write amplification 2.60). The first compaction is kUniversalSizeAmplification: 4 sorted runs make the size amplification 300%, above the 200% limit. The later ones are kUniversalSizeRatio. Each compaction rewrites the previous merged run together with the L0 files flushed since, so the inputs keep growing (4 → 7 → 16 files). Output to L6 is cut into 64 MiB files (target_file_size_base). Universal compaction only does trivial moves when allow_trivial_move is turned on (it is off by default), so even sorted runs that do not overlap were rewritten.
  • Cost of the merges. With one compaction thread, the long universal merges let L0 grow to 15 files (leveled peaked at 4), and the final settle took 6.0 s against 1.3 s for leveled. Universal ends with fewer, larger files (L0=1 L6=12: two sorted runs, below the trigger of 4). Leveled ends with L0=2 L5=5 L6=13.
  • Index. Each 64 KiB data block (about 19 KB after LZ4) has one index entry: separator key → (offset, size). A separator is at least every key in its block and smaller than the first key of the next block, and RocksDB shortens it where it can (for example 000560829 or 00056089 instead of a full 10-digit key). The last entry in each file is the file's largest key. The index stores user keys (no sequence numbers) and delta-encoded block handles, so a 78,000-order file has a 47 KB index of about 2,100 entries.

 26    static final int KEY_WIDTH = 10;
 27    private static final String KEY_FIELD = "{\"O_ORDERKEY\":";
 28    private static final byte[] NEWLINE = {'\n'};
 29    private static final byte[] COMMA_NEWLINE = {',', '\n'};

 34    static DumpReport dump(Path cordersDb, Path jsonFile) throws RocksDBException, IOException {
 35        Files.createDirectories(jsonFile.toAbsolutePath().getParent());
 36        long started = System.nanoTime();
 37        long orders = 0;
 38        long bytes = 0;
 39        String firstKey = null;
 40        String lastKey = null;
 41        try (Options options = new Options().setCreateIfMissing(false);
 42             RocksDB db = RocksDB.openReadOnly(options, cordersDb.toString());
 43             RocksIterator it = db.newIterator();
 44             OutputStream out = new BufferedOutputStream(Files.newOutputStream(jsonFile), 1 << 20)) {
 45            out.write('[');
 46            for (it.seekToFirst(); it.isValid(); it.next()) {
 47                out.write(orders == 0 ? NEWLINE : COMMA_NEWLINE);
 48                byte[] value = it.value();
 49                out.write(value);
 50                bytes += value.length;
 51                lastKey = new String(it.key(), StandardCharsets.US_ASCII);
 52                if (firstKey == null) {
 53                    firstKey = lastKey;
 54                }
 55                orders++;
 56            }
 57            out.write(NEWLINE);
 58            out.write(']');
 59            out.write(NEWLINE);
 60        }
 61        return new DumpReport(cordersDb, jsonFile, orders, bytes, Files.size(jsonFile),
 62                firstKey, lastKey, System.nanoTime() - started);
 63    }

 66        return new BufferedReader(new InputStreamReader(Files.newInputStream(jsonFile), StandardCharsets.UTF_8),

 68    }

 70    /** Returns the order document on this line, or null for the array brackets. */
 71    static String document(String line) {
 72        if (line.isEmpty() || line.equals("[") || line.equals("]")) {
 73            return null;
 74        }
 75        return line.endsWith(",") ? line.substring(0, line.length() - 1) : line;
 76    }
 77
 78    /** 10-digit zero-padded O_ORDERKEY, the same key Lab 08 used. */
 79    static byte[] key(String document) {
 80        if (!document.startsWith(KEY_FIELD)) {
 81            throw new IllegalArgumentException("document does not start with O_ORDERKEY: "
 82                    + document.substring(0, Math.min(60, document.length())));
 83        }
 84        int start = KEY_FIELD.length();
 85        int end = start;
 86        while (end < document.length() && Character.isDigit(document.charAt(end))) {
 87            end++;
 88        }
 89        int digits = end - start;
 90        if (digits == 0 || digits > KEY_WIDTH) {
 91            throw new IllegalArgumentException("bad O_ORDERKEY in " + document.substring(0, end));
 92        }
 93        byte[] key = new byte[KEY_WIDTH];
 94        int pad = KEY_WIDTH - digits;
 95        for (int i = 0; i < KEY_WIDTH; i++) {
 96            key[i] = i < pad ? (byte) '0' : (byte) document.charAt(start + i - pad);
 97        }
 98        return key;
 99    }

 14/**
 15 * Reads the index block of a RocksDB block-based SSTable.
 16 *
 17 * RocksJava has no API for the index block, so this decodes the on-disk
 18 * format directly (RocksDB wiki "Rocksdb BlockBasedTable Format"):
 19 *
 20 * <pre>
 21 *   [data block 1] ... [data block N] [meta blocks] [metaindex block] [index block] [footer]
 22 *   footer (53 bytes, format_version 1..5):
 23 *     checksum type (1) | metaindex handle | index handle | padding to 41 bytes
 24 *     | format_version (fixed32) | magic number (fixed64)
 25 *   block = contents + trailer (compression type 1 byte + checksum 4 bytes)
 26 *   index entry = separator key -> BlockHandle(offset, size) of one data block
 27 * </pre>
 28 *
 29 * Tables are written with format_version=5, an uncompressed binary-search
 30 * index, and the default index_block_restart_interval of 1.
 31 */
 32final class SstIndex {
 33
 34    static final long BLOCK_BASED_MAGIC = 0x88e241b785f4cff7L;
 35    static final int FOOTER_LENGTH = 53;
 36    static final int BLOCK_TRAILER = 5;
 37
 38    private SstIndex() {
 39    }
 40
 41    record Handle(long offset, long size) {
 42    }
 43
 44    /** One index entry. {@code sequence} is -1 when the index stores user keys. */
 45    record Entry(byte[] key, long sequence, Handle block) {
 46        String keyText() {
 47            return new String(key, StandardCharsets.US_ASCII);
 48        }
 49    }
 50
 51    record Index(int formatVersion, Handle metaindex, Handle index, int restarts, List<Entry> entries) {
 52    }
 53
 54    static Index read(Path sst, boolean keyIsUserKey, boolean valueDeltaEncoded) throws IOException {
 55        try (FileChannel ch = FileChannel.open(sst, StandardOpenOption.READ)) {
 56            long length = ch.size();
 57            ByteBuffer footer = read(ch, length - FOOTER_LENGTH, FOOTER_LENGTH);
 58            long magic = footer.getLong(FOOTER_LENGTH - 8);
 59            if (magic != BLOCK_BASED_MAGIC) {
 60                throw new IOException(sst + ": not a block-based table (magic " + Long.toHexString(magic) + ")");
 61            }
 62            int formatVersion = footer.getInt(FOOTER_LENGTH - 12);
 63            if (formatVersion < 1 || formatVersion > 5) {
 64                throw new IOException(sst + ": footer format_version " + formatVersion + " is not supported");
 65            }
 66            footer.position(1); // skip checksum type
 67            Handle metaindex = new Handle(varint64(footer), varint64(footer));
 68            Handle index = new Handle(varint64(footer), varint64(footer));
 69
 70            int size = Math.toIntExact(index.size());
 71            ByteBuffer block = read(ch, index.offset(), size + BLOCK_TRAILER);
 72            int compression = block.get(size) & 0xff;
 73            if (compression != 0) {
 74                throw new IOException(sst + ": index block is compressed (type " + compression + ")");
 75            }
 76            block.limit(size);
 77            int restarts = block.getInt(size - 4) & 0x7fffffff;
 78            List<Entry> entries = entries(block, size - 4 - 4 * restarts, keyIsUserKey, valueDeltaEncoded);
 79            return new Index(formatVersion, metaindex, index, restarts, entries);
 80        }
 81    }
 82
 83    /**
 84     * Entry layout: shared (varint32) | non_shared (varint32) | [value length (varint32)]
 85     * | key delta | value. With delta-encoded values (format_version >= 4) there is no
 86     * value length; an entry that shares no key bytes stores a full BlockHandle, and
 87     * any other entry stores only the signed size change from the previous block.
 88     */
 89    private static List<Entry> entries(ByteBuffer block, int end, boolean keyIsUserKey, boolean valueDeltaEncoded) {
 90        List<Entry> entries = new ArrayList<>();
 91        byte[] key = new byte[0];
 92        Handle previous = null;
 93        block.position(0);
 94        while (block.position() < end) {
 95            int shared = (int) varint64(block);
 96            int nonShared = (int) varint64(block);
 97            int valueLength = valueDeltaEncoded ? -1 : (int) varint64(block);
 98            byte[] next = Arrays.copyOf(key, shared + nonShared);
 99            block.get(next, shared, nonShared);
100            key = next;
101
102            Handle handle;
103            if (valueDeltaEncoded && shared > 0 && previous != null) {
104                long delta = zigzag(varint64(block));
105                handle = new Handle(previous.offset() + previous.size() + BLOCK_TRAILER, previous.size() + delta);
106            } else {
107                int valueStart = block.position();
108                handle = new Handle(varint64(block), varint64(block));
109                if (valueLength >= 0) {
110                    block.position(valueStart + valueLength);
111                }
112            }
113            previous = handle;
114
115            if (keyIsUserKey) {
116                entries.add(new Entry(key, -1, handle));
117            } else {
118                // Internal key: user key + fixed64 (sequence << 8 | value type).
119                int userLength = key.length - 8;
120                long packed = ByteBuffer.wrap(key, userLength, 8).order(ByteOrder.LITTLE_ENDIAN).getLong();
121                entries.add(new Entry(Arrays.copyOf(key, userLength), packed >>> 8, handle));
122            }
123        }
124        return entries;
125    }
126
127    private static ByteBuffer read(FileChannel ch, long offset, int length) throws IOException {
128        ByteBuffer buf = ByteBuffer.allocate(length).order(ByteOrder.LITTLE_ENDIAN);
129        while (buf.hasRemaining()) {
130            if (ch.read(buf, offset + buf.position()) < 0) {
131                throw new IOException("unexpected end of file at " + (offset + buf.position()));
132            }
133        }
134        return buf.flip();
135    }
136
137    private static long varint64(ByteBuffer buf) {
138        long result = 0;
139        for (int shift = 0; shift < 64; shift += 7) {
140            byte b = buf.get();
141            result |= (long) (b & 0x7f) << shift;
142            if ((b & 0x80) == 0) {
143                return result;
144            }
145        }
146        throw new IllegalStateException("varint longer than 10 bytes");
147    }
148
149    private static long zigzag(long n) {
150        return (n >>> 1) ^ -(n & 1);
151    }
