  2. Retrieve all orders for a customer.
  3. Retrieve all line items belonging to an order.
  4. Retrieve the details required to display a customer's order history.
  5. List all items ordered by a customer in a year.
  6. List all items a customer ordered in the previous year (year-1) but has not bought this year.
  7. Show the total value of a customer's orders in a given year.

2. Database design

Every query is driven by one customer (1, 2, 4, 5, 6, 7) or one order (3), so the data is modelled as aggregates in a single table TPCH with a composite primary key pk (partition, string) and sk (sort, string):

  • A customer's partition CUST#<custkey> holds the profile item (sk = PROFILE) and one item per order.
  • An order item's sort key ORDER#<orderdate>#<orderkey> starts with the date, so the orders of a customer are stored in date order and "orders of year Y" is just begins_with(sk, "ORDER#Y"). The 10-digit zero-padded order key at the end keeps the key unique.
  • The line items of an order are embedded in the order item as a list of maps (the CORDERS aggregate of Lab 08). TPC-H orders have 1–7 line items, so an item is at most a few KB, far below the 400 KB limit, and every order-level query gets the line items for free.
  • Query 3 is addressed by order key only, so a global secondary index OrderIndex with partition key orderkey (projection KEYS_ONLY) maps an order key to the order's (pk, sk); a GetItem then returns the order with its line items. KEYS_ONLY keeps the index small: it stores only pk, sk and orderkey per order.
  • No Scan is needed for any of the seven queries; every query is a key lookup or a single-partition Query.

4. How it works

  • Model classes (Customer, Order, LineItem): @DynamoDbBean POJOs. pk/sk carry @DynamoDbPartitionKey/@DynamoDbSortKey; Order.orderkey carries @DynamoDbSecondaryPartitionKey(indexNames = "OrderIndex"); Order.lineitems is a List<LineItem>, which the Enhanced Client maps to a DynamoDB list of maps. Money columns are BigDecimal (DynamoDB numbers).
  • Create (Schema.create): DynamoDbTable<Order>.createTable(...) with an EnhancedGlobalSecondaryIndex for OrderIndex; the key schema and attribute definitions come from the bean annotations. On-demand (PAY_PER_REQUEST) billing.
  • Load (TpchLoader): customer.tbl rows become profile items. orders.tbl and lineitem.tbl are both written by dbgen in ascending order key, so they are merge-joined in one streaming pass: read an order, take its line items from the head of lineitem.tbl, put the list into the order bean. Items go out as BatchWriteItem requests of 25 (DynamoDbEnhancedClient.batchWriteItem with a WriteBatch per request), 8 writer threads, unprocessed items re-sent with backoff.
  • Queries (Queries, one method each): DynamoDbTable.getItem(Key), DynamoDbTable.query(QueryConditional.sortBeginsWith(...)) and DynamoDbIndex.query(QueryConditional.keyEqualTo(...)). Query results are iterated page by page; the program counts the pages and the elapsed time. Query 6 is two Queries plus a set difference of part keys in Java; Query 7 sums totalprice and cross-checks it against Σ extendedprice × (1 − discount) × (1 + tax) of the embedded line items.

  • Q3 costs one index Query plus one GetItem, the price of a KEYS_ONLY projection; projecting ALL would make it one request at the cost of duplicating every order (with its line items) into the index.
  • Q6 cannot be a single DynamoDB request (set difference is not a key condition); it is two year Queries and a TreeSet difference in the client. TPC-H part keys are random over 200,000 parts, so the two years share no part and the answer is every part of year-1.

235            }

250    /** Groups items into batches of 25 and writes them with BatchWriteItem on a thread pool. */
251    static final class BatchWriter<T> {
252
253        private final DynamoDbEnhancedClient enhanced;
254        private final DynamoDbTable<T> table;
255        private final Class<T> type;
256        private final String label;
257        private final ExecutorService pool = Executors.newFixedThreadPool(THREADS);
258        private final Semaphore inFlight = new Semaphore(THREADS * 4);
259        private final AtomicLong written = new AtomicLong();
260        private final AtomicLong retries = new AtomicLong();
261        private final AtomicReference<Throwable> failure = new AtomicReference<>();
262        private final long started = System.nanoTime();
263        private List<T> batch = new ArrayList<>(BATCH_SIZE);
264        private long submitted;
265
266        BatchWriter(DynamoDbEnhancedClient enhanced, DynamoDbTable<T> table, Class<T> type, String label) {
267            this.enhanced = enhanced;
268            this.table = table;
269            this.type = type;
270            this.label = label;
271        }
272
273        void add(T item) throws InterruptedException {
274            batch.add(item);
275            if (batch.size() == BATCH_SIZE) {
276                flushBatch();
277            }
278        }
279
280        private void flushBatch() throws InterruptedException {
281            if (batch.isEmpty()) {
282                return;
283            }
284            Throwable f = failure.get();
285            if (f != null) {
286                throw new IllegalStateException(label + " batch write failed", f);
287            }
288            List<T> items = batch;
289            batch = new ArrayList<>(BATCH_SIZE);
290            inFlight.acquire();
291            pool.execute(() -> {
292                try {
293                    write(items);
294                } catch (Throwable t) {
295                    failure.compareAndSet(null, t);
296                } finally {
297                    inFlight.release();
298                }
299            });
300            submitted += items.size();
301            if (submitted % 100_000 == 0) {
302                progress();
303            }
304        }
305
306        private void write(List<T> items) throws InterruptedException {
307            List<T> pending = items;
308            int attempt = 0;
309            while (!pending.isEmpty()) {
310                WriteBatch.Builder<T> wb = WriteBatch.builder(type).mappedTableResource(table);
311                for (T item : pending) {
312                    wb.addPutItem(item);
313                }
314                BatchWriteResult result = enhanced.batchWriteItem(
315                        BatchWriteItemEnhancedRequest.builder().writeBatches(wb.build()).build());
316                List<T> unprocessed = result.unprocessedPutItemsForTable(table);
317                written.addAndGet(pending.size() - unprocessed.size());
318                if (!unprocessed.isEmpty()) {
319                    retries.incrementAndGet();
320                    Thread.sleep(Math.min(1000L, 50L << Math.min(attempt++, 4)));
321                }
322                pending = unprocessed;
323            }
324        }
325
326        void finish() throws Exception {
327            flushBatch();
328            pool.shutdown();
329            pool.awaitTermination(1, TimeUnit.DAYS);
330            Throwable f = failure.get();
331            if (f != null) {
332                throw new IllegalStateException(label + " batch write failed", f);
333            }
334            progress();
335        }
336
337        long written() {
338            return written.get();
339        }
340
341        long retries() {
342            return retries.get();
343        }
344
345        private void progress() {
346            double sec = (System.nanoTime() - started) / 1e9;
347            System.out.printf(Locale.ROOT, "  %-8s submitted %,10d  written %,10d  %7.1f s  %,7.0f items/s%n",
348                    label, submitted, written.get(), sec, written.get() / Math.max(sec, 1e-9));
349        }
350    }

48                        AwsBasicCredentials.create("1234", "1234")))
